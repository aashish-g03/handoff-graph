Who one engineer passes work to

The bot routed 405 issues to one VS Code engineer between June and October. Each time they handed one on, the learner wrote a HANDED_OFF edge. Names are pseudonymised here.

MATCH (a:Person {login: $first_pick})
      -[h:HANDED_OFF]->(b:Person)
WHERE h.at < $t
  AND h.kind IN ['forward','reassign']
RETURN b.login, count(h) AS times
ORDER BY times DESC
0.6 ms on FalkorDB. The router turns these counts into a prior: kept 238 of 405, handed 75 to B, 64 to C…
Edge width is proportional to the number of handoffs. Data: real microsoft/vscode assignment history, Jun 1 – Oct 15, 2026.
