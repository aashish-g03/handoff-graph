Who one engineer passes work to

The bot routed 405 issues to one VS Code engineer (A) between June and October. Each time A handed one on, the learner wrote a HANDED_OFF edge. Edge width shows how often.

MATCH (a:Person {login: $first_pick})-[h:HANDED_OFF]->(b:Person)
WHERE h.at < $t AND h.kind IN ['forward','reassign']
RETURN b.login, count(h) AS times ORDER BY times DESC
Runs in 0.6 ms. The router turns the counts into a prior: kept 238 of 405, handed 75 to B, 64 to C, and so on. Real microsoft/vscode data, names replaced with letters.
